Main inspiration sources
========================

The community `k8s-at-home <https://github.com/topics/k8s-at-home>`_ has been a
very valuable source of inspiration, experience and ideas. Especially the
following projects helped to build up this project:

- https://github.com/bjw-s-labs/home-ops has served as inspiration when
  building the initial shape of this repository.

- https://github.com/onedr0p/home-ops and
  https://github.com/onedr0p/cluster-template also inspired the initial
  shape of this repository.

- https://github.com/toboshii/home-ops
