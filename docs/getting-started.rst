===============
Getting Started
===============

The `demo-ops <https://codeberg.org/business-operations/demo-ops>`_
repository is the recommended starting point. It provides a complete
working example that deploys a single-node cluster using
business-operations as a Git submodule.

See the `demo-ops documentation
<https://business-operations.codeberg.page/demo-ops/>`_ for
step-by-step instructions covering NixOS deployment, secrets setup,
and Kubernetes bootstrap.
