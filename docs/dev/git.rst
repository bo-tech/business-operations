==============
 Git Handling
==============


Dependencies
============

Instance repositories integrate ``business-operations`` via the folder
``/external`` using git submodules.


Cloning from other places
--------------------------

It is possible to manually clone ``business-operations`` into
``/external/business-operations`` from a different source than the one noted in
the submodule configuration for local work.

The Flux level integration will require the referred to commit to be available
in the upstream location though.
